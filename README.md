# 🎮 EduQuest - L'école en ligne gamifiée

Une plateforme d'apprentissage interactive où tu apprends **tous les sujets** (maths, français, histoire, sciences, langues, programmation...) en gagnant des **XP, des niveaux et des badges**.

## 🎯 Concept

- **Apprendre** : exercices courtes et progressives sur tous les sujets
- **Gagner des XP** : chaque exercice complété = XP
- **Monter des niveaux** : atteindre des paliers ouvre de nouvelles fonctionnalités
- **Acheter des badges** : avec tes niveaux, tu débloques et achètes des badges
- **Badges ultra importants** : c'est LA motivation, le prestige, la preuve de tes compétences
- **S'amuser** : combos, streaks, défis quotidiens, leaderboards

## 📊 Système de Progression

```
XP → Niveaux → Badges → Prestiges
```

### Exemple
- Niveau 1 → Tu peux acheter "Débutant en Maths"
- Niveau 5 → Tu peux acheter "Maîtrise du Français"
- Niveau 10 → Tu peux acheter "Expert Python"
- Niveau 20 → Tu peux acheter "Génie Scientifique"

## 🏆 Types de Badges

- **Badges de Maîtrise** : "Expert en Maths", "Master Python"
- **Badges de Streak** : "7 jours d'affilée", "30 jours consécutifs"
- **Badges de Défi** : "100 XP en 1 jour", "Quiz parfait"
- **Badges de Collection** : "10 badges collectés", "50 badges"
- **Badges d'Amitié** : "Aider 5 amis"
- **Badges Saisonniers** : "Champion d'Automne"

## 🎮 Fonctionnalités Clés

### Écrans Principaux
1. **Accueil** - Vue d'ensemble, XP, niveau, prochains badges
2. **Apprentissage** - Choix des matières et des cours
3. **Mission du Jour** - Challenge quotidien avec bonus XP
4. **Boutique de Badges** - Acheter avec tes niveaux
5. **Profil** - Tous tes badges, statistiques, achievements
6. **Leaderboard** - Classement global ou entre amis
7. **Paramètres** - Notifications, thème, langue

### Mécanique de Jeu
- **XP System** : 10-100 XP par exercice (difficulté variable)
- **Streaks** : bonus si tu joues tous les jours
- **Combos** : bonus cumulatif si tu enchaines les exercices
- **Défis Quotidiens** : 1 mission spéciale = gros bonus XP
- **Boss Fights** : examen complet d'une matière = énorme récompense
- **Multiplier** : plus ton niveau monte, plus tu gagnes d'XP

## 💾 Stack Technique (Exemple)

- **Frontend** : React / Vue / Next.js
- **Backend** : Node.js / Python / Django
- **Database** : PostgreSQL / MongoDB
- **Real-time** : WebSockets pour défis en temps réel
- **Auth** : JWT / OAuth
- **Gamification** : système de points personnalisé
